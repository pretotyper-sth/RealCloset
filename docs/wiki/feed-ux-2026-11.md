# 피드 UI·문구 수정 내역 — 2026-11-01

## UI 수정

- 아이템 가로 목록: 자동 스냅을 제거해 스크롤한 지점에 정지. 카드 고정 폭 76%/최대 280px을 내용 기준/최대 212px로 변경하고, 간격은 12px → 8px. 기존 전체 아이템 목록 바텀시트 연결 유지.
- 꾸미기 패널: 스티커·펜·이미지 등 제목 왼쪽 정렬. 텍스트 패널에도 같은 제목 추가. 모바일 텍스트 패널은 새 제목이 들어갈 공간만큼 기본 높이 150px → 190px.
- 요소 순서 버튼: 뒤로·앞으로·복제·삭제를 모두 테두리·타원·그림자 없는 36px 높이/11px 글자/6px 8px 안쪽 여백의 텍스트 버튼으로 통일. 비활성 상태와 실제 레이어 순서 동작 유지.
- 내 피드: 모바일에서 전체 제목·카드 시작·오른쪽 아이콘 끝을 화면 양옆 16px에 정렬.

## 검증

- 격리된 로컬 화면에서 390×844 모바일 및 1280×900 PC 확인. 실제 사용자 계정/유료 API 호출 없이 테스트용 응답만 사용.
- 모바일 가로 목록 scrollLeft=19.5px에서 정지(최대 46px), scroll-snap-type=none, 간격 8px. 아이템 클릭 시 기존 3개 전체 목록 열림.
- 모바일 내 피드 제목/카드 left=16px, 마지막 아이콘 right=374px(390px 화면), 페이지 가로 넘침 없음.
- 스티커/펜/이미지/텍스트 제목과 36px 버튼 확인. 레이어 순서·피드 빈 상태 테스트 6개 통과.
- 백엔드 AST 비교에서 문자열 이외의 로직 차이 없음. 백엔드 전체 피드 테스트는 로컬 FastAPI 의존성 미설치로 실행하지 못함.
- 변경 JSX lint 오류 없음(기존 hook/순수성 경고 유지). 빌드 결과와 배포 여부는 작업 로그 참고.
